# 1584. Min Cost to Connect All Points

**Сложность:** Medium

**Ссылка:** https://leetcode.com/problems/min-cost-to-connect-all-points/

## Условие

Дан массив `points`, где `points[i] = [xi, yi]` — точка на плоскости. Стоимость соединения двух точек — их **манхэттенское расстояние** `|xi − xj| + |yi − yj|`.

Нужно соединить все точки так, чтобы между любой парой был **ровно один** путь, с минимальной суммарной стоимостью. Вернуть эту стоимость.

## Примеры

```
points = [[0,0],[2,2],[3,10],[5,2],[7,0]]   → 20
points = [[3,12],[-2,5],[-4,1]]             → 18
```

## Ограничения

- `1 <= points.length <= 1000`
- `-10^6 <= xi, yi <= 10^6`
- Все точки различны.

## Решение

«Ровно один путь между любой парой при минимальной сумме» — это дословно **минимальное остовное дерево** (MST) на полном графе, где вес ребра = манхэттенское расстояние. Строим через **Крускал + Union Find**:

1. Собираем все рёбра `[from, to, cost]` для пар `i < j` (граф полный → `n(n−1)/2` рёбер).
2. Сортируем по весу по возрастанию.
3. Идём от дешёвого к дорогому, для каждого ребра пробуем `union(from, to)`:
   - слил две разные компоненты (`union → true`) → ребро в остов, прибавляем `cost`;
   - точки уже связаны (`union → false`) → ребро замкнуло бы цикл, пропускаем.
4. Ранний выход по `count === 1` — как только всё в одной компоненте, остов из `n−1` рёбер собран.

Union Find на **индексах точек** (`0..n−1`); вес в структуру не попадает — он живёт снаружи, в накоплении `total`.

## Сложность

- Время: **O(n² log n)** — доминирует сортировка `n²` рёбер.
- Память: **O(n²)** — список рёбер.

## Заметки

- Union-by-size + сжатие путей дают почти `O(α(n))` на операцию UF.
- Булев возврат `union` («слил / уже связаны») чисто разделяет «взять ребро» и «пропустить» — без отдельного `connected` перед ним.
- Манхэттен целочисленный (без `√`/float), поэтому `total` остаётся целым.
- Альтернатива — **Прим** за `O(n²)` времени и `O(n)` памяти: на плотном (полном) графе он выигрывает, т.к. не строит список рёбер и не сортирует. Крускал выбран сознательно — обкатать Union Find. Сравнение Прим/Крускал — в obsidian-заметке.
