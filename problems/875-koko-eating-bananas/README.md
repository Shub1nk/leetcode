# 875. Koko Eating Bananas

**Сложность:** Medium

**Ссылка:** https://leetcode.com/problems/koko-eating-bananas/

## Условие

Коко любит бананы. Есть массив `piles`, где `piles[i]` — число бананов в `i`-й куче, и `h` часов до возвращения охраны.

Коко выбирает скорость поедания `k` (бананов в час). Каждый час она берёт одну кучу и съедает из неё `k` бананов; если в куче осталось меньше `k`, она доедает кучу и в этот час больше не ест.

Нужно вернуть **минимальную** целую скорость `k`, при которой Коко успеет съесть все бананы за `h` часов.

## Примеры

```text
Ввод:  piles = [3,6,7,11], h = 8
Вывод: 4
```
```text
Ввод:  piles = [30,11,23,4,20], h = 5
Вывод: 30
```
```text
Ввод:  piles = [30,11,23,4,20], h = 6
Вывод: 23
```

## Ограничения

- `1 ≤ piles.length ≤ 10⁴`
- `piles.length ≤ h ≤ 10⁹`
- `1 ≤ piles[i] ≤ 10⁹`

## Решение

Бинарный поиск **по ответу**: ищем не элемент массива, а само число — минимальную скорость `k`.

Для фиксированной `k` время на одну кучу — `⌈piles[i] / k⌉` часов (округление вверх: остаток кучи требует ещё целый час). Суммарное время

```
hours(k) = Σ ⌈piles[i] / k⌉
```

монотонно **не возрастает** по `k`: чем выше скорость, тем меньше (или столько же) часов. Значит применим бинарный поиск наименьшего `k`, при котором `hours(k) ≤ h`.

**Границы:**
- `left = 1` — минимальная осмысленная скорость (ответ может быть меньше самой маленькой кучи).
- `right = max(piles)` — при такой скорости каждая куча съедается за час, всего часов = число куч ≤ `h`, так что заведомо успеваем.

**Ранний выход:** при `piles.length === h` на каждую кучу приходится ровно час → ответ сразу `max(piles)`.

Середину диапазона берём через shared-хелпер `getMid` (нижняя середина без переполнения).

## Сложность

- **Время:** `O(n · log(max(piles)))`, где `n = piles.length` — на каждой из `~log` итераций проходим массив.
- **Память:** `O(1)`.

## Заметки

- `⌈piles[i] / k⌉` считаем целочисленно: `⌊(piles[i] + k - 1) / k⌋` (или через остаток `%`). Добавка `k - 1` доводит любой ненулевой остаток до следующей единицы, а деление без остатка не задевает — отсюда и потолок без float.
